## What it is
Ender IO — the classic tech mod rewritten for modern Minecraft: compact item/fluid/energy/redstone conduits, machines (SAG mill, alloy smelter, farming station, powered spawner, stirling/solar/soul power, vacuum chests, obelisks, vat...), capacitors, travel anchors, tools/armor. Core repo is `Team-EnderIO/EnderIO` (single monorepo); siblings: `Endergy` (addon), `Regilite` (archived reg-helper), `Website` (docs).

## Architecture and repo layout
- Modules: `endercore` (small core lib), `enderio` (the mod), `enderio-modded-conduits` (Mekanism/AE2/RS conduits).
- Main packages under `enderio/src/main/java/com/enderio/enderio/`: `init/` (one DeferredRegister holder per registry: `EIOBlocks`, `EIOItems`, `EIOBlockEntities`, `EIOMenus`, `EIORecipes`, `EIOConduitTypes`, `EIODataComponents`...), `content/` (one folder per feature, e.g. `content/machines/sag_mill/` with its Block/BlockEntity/Menu/Screen), `foundation/` (shared infra: energy, fluid, inventory, menu, model, recipe, network), `api/` (public API incl. `api/conduits`: `Conduit`, `ConduitType`, capability accessors), `client/`, `compat/`, `mixin/`.
- Conduit types/data/connection/node/network-context are all NeoForge registries; networks run on GraphLib3 (gigaherz), mirrored on their maven. Conduit hosting: `content/conduits/bundle/ConduitBundleBlock`.
- Networking: custom-payload packets + client/server handlers in `foundation/network/` (`EIONetwork`, `menu_sync/` for container syncing).
- Dedicated `datagen` and `gametest` sourceSets; generated resources committed under `src/generated/resources`. Athena CTM for connected textures.

## Practices worth borrowing
- `enderio/.../init/` — clean one-class-per-registry DeferredRegister pattern.
- `content/<feature>/` co-location of every class a feature needs (great template for siasworkshop features).
- `foundation/network/` packet/handler split plus `menu_sync` container-data syncing.
- `api/conduits/` registry-driven conduit-type design + `ConduitBundleBlock` multi-part hosting.
- `gradle/libs.versions.toml` with `strictly` version pins; datagen as a separate sourceSet.

## Watch-outs
