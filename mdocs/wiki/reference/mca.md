## What it is
- Villager-overhaul mod: replaces squidward villagers with human NPCs — dialogue, relationships/marriage/children, genetics, chores, village ranks/buildings. Single-player and SMP.
- Two codebases matter: the stale original (WildBamaBoy, MC 1.12 era) and the maintained rewrite MCA Reborn (Luke100000 et al., 2021+).

## Status on MC 1.21.1 / NeoForge
- Original (stale): `WildBamaBoy/minecraft-comes-alive`, default branch `1.12.2-6.0.1`, last push 2022-05 (final hotfix only). Forge 1.12.2, legacy MCP mappings/architectury-era tooling. Not portable directly.
- Maintained successor — MCA Reborn: https://github.com/Luke100000/minecraft-comes-alive, default branch `1.21.1`, GPL-3.0, actively pushed (Oct 2026).

## Architecture and repo layout
- Original: single-module Forge 1.12.2 Gradle project, `src/main/java/mca/...` (package-per-domain: core, entity, items, network via simple channels), heavy NBT/IDataFixer style, no data-driven content.
- Reborn (1.21.1): three-module Gradle project (`common/`, `neoforge/`, `fabric/`) — thin loader entrypoints (`neoforge/src/main/java/net/conczin/mca/neoforge/CommonNeoForge.java`) over ~490 common classes in `net.conczin.mca`:
  - `registry/` — registration as static-map interfaces (`ItemsMCA`, `EntitiesMCA`, `SoundsMCA`, `TagsMCA`, `TradeOffersMCA`), not DeferredRegister; attributes co-registered in `EntitiesMCA.ATTRIBUTES`.
  - `network/` — loader-agnostic payload abstraction (`Network.Registrar`/`Sender` interfaces, `HandleablePayload`, StreamCodec-based) implemented per-loader.
  - `entity/` — `VillagerEntityMCA`, AI/relationships, plus `resources/` reload listeners loading data-driven JSON: dialogues, gifts (datapack `data/<mod>/gifts/`), names, skins, building types, tasks, rank.
  - `client/` — custom humanoid rendering, skin catalog, GUI screens, in-game book system; mixins (`mixin/`).

## Practices worth borrowing
- Multi-loader `common/` + tiny `neoforge/` shim setup — copy its `settings.gradle`/`build.gradle` split.
- Data-driven dialogue/gift/name systems: `common/.../resources/Dialogues.java`, `data/mca/dialogues/`, `data/*/gifts/`.
- Registry idiom: `common/src/main/java/net/conczin/mca/registry/ItemsMCA.java` (map + static constants).
- Networking abstraction: `common/src/main/java/net/conczin/mca/network/Network.java`.
- `example/skins/` — skin/content addon pack format.

## Watch-outs
- GPL-3.0 copyleft on both; don't lift code into a non-GPL siasworkshop.
- Original repo is 1.12-only with old mappings — inspiration only.
- Reborn's custom registry pattern trades NeoForge conveniences (DeferredRegister, data attachments) for loader portability; Mixin-heavy client rendering.
- CurseForge disables 3rd-party jar sharing — no Curse Maven for dev deps.
- **No worldgen**: MCA Reborn 1.21.1 ships zero structures/template pools — its villages are runtime `SavedData` (`VillageManager` scans player-built structures against `data/mca/building_types/*.json` block tags). NOT a reference for village structure generation; for that see StructureTutorialMod, ChoiceTheorem's Overhauled Village, Repurposed Structures.
