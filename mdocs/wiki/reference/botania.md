## What it is
Botania — Vazkii's flagship "natural magic tech" mod (magic flowers, Mana, automation without pipes/GUIs/numbers). Actively maintained; Patchouli-book-driven Lexica Botania; requires Patchouli + Curios (Forge/Neo) / Trinkets (Fabric).

## Status on MC 1.21.1 / NeoForge
- Latest released code is on default branch `1.20.x` (`gradle.properties`: `minecraft_version=1.20.1`, build 457). No 1.21.1 release on CurseForge/Modrinth as of 2026-10-07.
- A 1.21.1 build exists only in progress: active branch `1.21.1-porting` (committed Oct 6, 2026). Its `gradle.properties` targets MC 1.21.1, NeoForge 21.1.229, Parchment 2024.11.17, Java 21, NeoForm — nearly the same stack as siasworkshop, so this branch is the correct reference.
- Multi-loader: `Xplat` (common) + `Fabric` + `NeoForge` Gradle subprojects; Garden of Glass skyblock addon built from the same repo.

## Architecture and repo layout
- `Xplat/src/main/java/vazkii/botania/{api,common,client,data,network,mixin,xplat,test}` — all game logic in `common`, platform hooks via `xplat/XplatAbstractions.java` and `ClientXplatAbstractions.java`.
- Registration is hand-rolled, not DeferredRegister: giant static-field holder classes (`common/block/BotaniaBlocks.java`, `common/item/BotaniaItems.java`, `common/block/block_entity/BotaniaBlockEntities.java`) bound to registries via consumer `init(...)` methods.
- Capabilities: `common/BotaniaCapabilities.java` + `common/internal_caps/` — own Mana/capability abstraction over both loaders' attachment systems.
- Data-driven: flower behavior via data components (`common/component/`), full datagen in `common/data/`, Lexica via Patchouli JSON.
- Networking in `network/`; heavy mixins (`common/mixin/`, `client/`); Spotless + GitHub Actions CI.

## Practices worth borrowing
- Mana capability design: `common/BotaniaCapabilities.java`, `common/internal_caps/` — clean capability/attachment factoring.
- Data-component-driven flower content: `common/block/flower/`, `common/component/`.
- Corporea (in-world item indexing/autocrafting, no GUI): `common/integration/corporea/`, `api/block/corporea/`.
- Comprehensive datagen package (`common/data/`) covering blocks/items/loot/tags.
- Loader-neutral abstraction seam (`xplat/XplatAbstractions.java`) if siasworkshop ever goes multi-loader.

## Watch-outs
- License's copyleft-style clause: copying code into siasworkshop obligates open source + similar clause — study, don't lift.
- `1.21.1-porting` is unstable/porting-in-motion; APIs will churn.
- Xplat layering is a heavy abstraction for a NeoForge-only mod — borrow patterns, not structure.
- Mixins: in-dev dependency needs `mixin.env.disableRefMap=true` JVM arg.
- Own registration idiom means grepping for `DeferredRegister` finds nothing.
