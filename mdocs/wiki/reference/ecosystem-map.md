## Directly borrowable now (1.21.1-native, near-identical toolchain)

- **Ender IO** — the #1 structural reference: one-DeferredRegister-class-per-registry in `init/`, per-feature folders in `content/`, `foundation/` shared infra, datagen as separate sourceSet. Toolchain matches ours almost exactly (ModDevGradle 2.x, Parchment, Java 21, NeoForge 21.1.x).
- **MCA Reborn** — best reference for data-driven content (dialogues/gifts/names as datapack JSON) and a clean common/neoforge module split; GPL means look, don't lift.
- **GeckoLib / Bookshelf / Cloth Config** — add as dependencies (coordinates on their pages); MIT/LGPL linking is compatible with our All Rights Reserved stance.

## Inspiration only (older versions or restrictive licenses)

- **CoFH Thermal** — machine/augment/energy design patterns (1.20.x, NeoGradle-era APIs, custom license).
- **BiggerReactors + Phosphophyllite** — multiblock architecture; for 1.21.1-native multiblock code see Extreme Reactors / ZeroCore.
- **HarvestCraft** — farming/cooking design; HC1 is 1.12.2 ARR, HC2 is closed-source. Design lessons only.
- **Botania** — data-driven content and capability design from the `1.21.1-porting` branch; custom license forbids code lifting.

## Genre alignment

siasworkshop lies along the lines of these examples: machines/energy (Ender IO, Thermal, BiggerReactors), farming/cooking (HarvestCraft), villagers/social (MCA), magic-tech flora (Botania). When implementing a feature, start from the reference page for its genre.

## How to use these pages

Each reference page lists concrete practices with repo-relative paths. When an agent implements a feature, open the named repo/branch and study the pointed-at classes. Respect the borrow level: `code + structure` (copy freely, keep attribution), `structure only` (imitate architecture, write your own code), `inspiration` (concepts only), `dependency` (link the artifact, don't copy source).
