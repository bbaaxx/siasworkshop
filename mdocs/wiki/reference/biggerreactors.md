## What it is
- Full rewrite/continuation of Big Reactors (Erogenous Beef) by RogueLogix: multiblock fission reactors, turbines, heat exchangers, radiation-free big-power gen. Requires another mod to move/use energy.
- Companion library mods (git submodules): Phosphophyllite (multiblock API/registry framework) and Quartz (OpenGL/Vulkan rendering + GUI lib). Org overview: https://github.com/BiggerSeries/BiggerSeries

## Status on MC 1.21.1 / NeoForge
- No 1.21.x branch exists; 1.21.1 NeoForge build is absent. Latest branches: `master` = MC 1.20.4 + NeoForge 20.4.156-beta (last commit Feb 2024); `1.20.1` = Forge 47.1.0 + Parchment (last commit Nov 2024). Releases stop at 0.6.0-beta.10.x. Effectively dormant.

CurseForge: https://www.curseforge.com/minecraft/mc-mods/extreme-reactors. This is the repo to consult for 1.21.1-native multiblock code.

## Architecture and repo layout
- Root `build.gradle` uses NeoGradle 7.0.x (`net.neoforged.gradle.userdev`), Java 17, with `Phosphophyllite` and `Quartz` as included build submodules; mods.toml version ranges injected via `ProcessResources`.
- Package root `src/main/java/net/roguelogix/biggerreactors/`: `multiblocks/{reactor,reactor2,turbine,heatexchanger}` (each split into `blocks/`, `tiles/`, `containers/`, `client/`, `state/`, plus `ReactorMultiblockController.java` and a `simulation/` package per machine), `registries/`, `machine/`, `fluids/`, `items/`.
- No DeferredRegister — registration goes through Phosphophyllite's annotation-driven `Registry` (`new Registry(...)` in `BiggerReactors.java`), creative tabs pulled from the library mods.
- Data-driven behavior registries reloaded on data reload: `ReactorModeratorRegistry`, `TurbineCoilRegistry`, `FluidTransitionRegistry` (JSON-defined moderator/coil/fluid properties).
- Custom GPU-accelerated GUI rendering via Quartz; LWJGL OpenCL/Vulkan deps on runtime classpath.

## Practices worth borrowing
- Phosphophyllite multiblock framework (https://github.com/BiggerSeries/Phosphophyllite): controller/assembly validation, per-tile `state` sync — best-in-class multiblock reference.
- Data-reloadable JSON registries for block/fluid behavior (`src/main/java/net/roguelogix/biggerreactors/registries/`).
- Splitting each multiblock machine into self-contained packages (blocks/tiles/containers/client/simulation) under one `multiblocks/` root.
- Simulation core decoupled from Minecraft (`multiblocks/reactor/simulation/`) — pure logic, testable.

## Watch-outs
- Dead on 1.21.1 — code borrows as inspiration only; it uses NeoGradle 7 (not ModDevGradle), Java 17 (not 21), and pre-1.20.5 data component APIs.
- Custom `Registry` + submodule libs add learning curve; annotations are nonstandard vs. DeferredRegister.
- Author asks you not to redistribute built jars; honor the LGPL share-alike if you port code.
- Official wiki (biggerseries.net) returned HTTP 522 — likely down (unverified whether permanent).
